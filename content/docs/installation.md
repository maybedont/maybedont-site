Maybe Don't can be installed through several methods depending on your environment.

## Download Packages

The easiest way to get started is to download the package for your platform from the [Download page](/docs/download/). Available for Linux, macOS, and Windows.

## Docker/Container Installation

Maybe Don't is available as a container image from GitHub Container Registry:

```bash
# Using Docker
docker pull ghcr.io/maybedont/maybe-dont:v1.1.0

# Using Podman
podman pull ghcr.io/maybedont/maybe-dont:v1.1.0
```

See the [Container Deployment](/docs/containers/) section for detailed usage instructions.
